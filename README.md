# 🛒 SmartCart AI: E-Commerce Intelligence System

## Problem Statement
E-commerce platforms lose billions annually due to cart abandonment and irrelevant product suggestions. SmartCart AI analyzes user behavior to predict churn and recommend personalized products in real-time.

## Solution
A unified dashboard that provides:
1.  **Churn Prediction:** Identifies high-risk customers using Random Forest.
2.  **Behavioral Timeline:** Visualizes shopping intensity (Session-based analysis).
3.  **Product Recommendations:** Suggests items using Collaborative Filtering (User-Based).

## Tech Stack
- Python
- Pandas & NumPy (Data Processing)
- Scikit-Learn (Machine Learning)
- Streamlit (Dashboard/UI)
- Plotly (Interactive Visualizations)

## Installation & Setup

1. Clone the repo
2. Create virtual environment: `python3 -m venv .venv`
3. Activate it: `source .venv/bin/activate` (Mac) or `.venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Run the app: `streamlit run app.py`

Online Retail Dataset (UCI Machine Learning Repository)
